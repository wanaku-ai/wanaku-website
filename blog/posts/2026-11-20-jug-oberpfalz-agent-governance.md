# Guardrails for AI Agents: Live Coding with JUG Oberpfalz

Connecting an AI agent to an API raises a practical question: how do you govern what the agent can do?

For a discussion and a practical demonstration, check out **Guardrails for AI Agents: Wanaku in Front of a Java Webshop API** from JUG Oberpfalz.

This JUG Oberpfalz live coding session discusses the challenges of governing what agents can do and demonstrates how to tackle them with Wanaku in front of a Java webshop API.
